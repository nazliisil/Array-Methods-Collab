# Array-Methods-Collab
This is a project where the user can execute certain array methods.
The user can create an array of an arbitrary length, access the array's maximum and minimum, find the array average and display how each element differs from said average, and also find the sum of elements with odd and even indexes. 
User's choices are made on the array by pressing 1 to 6.
Changes can be made until the user presses Q to quit.
